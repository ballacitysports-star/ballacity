What it changes for members: a player's own Venmo, Cash App or other manual claim is refused for a game that is
cancelled, over, closed to joining, past its signup cutoff or full, for a player whose guardian has turned off game
participation, whom the host blocked, or who is outside the game's age range (unless on the roster or approved, where
PayPal's rules exempt them). Host "marked paid" rows and the service role's PayPal records are not checked; existing
claims are untouched. PayPal answers exactly as before.

refuses if any of the four functions has changed since; it reopens what the migration closed.
