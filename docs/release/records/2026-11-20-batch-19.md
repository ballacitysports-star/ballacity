- `listOrgMembers` (`src/lib/trainer-orgs.functions.ts`) reads `org_members` with the anonymous client.
- Production grants the `anon` role nothing on `org_members`. Only `authenticated` can read it, through the "Org-scoped members can view org members" rule.
- So a gym page's member list fails for everyone.
