# Pilot checklist

This page says whether the Phase 5 pilot can start. Plan: `docs/product/phase-5-validation-plan.md` (WP 5.0).

How to use it:

- Tick an item only when it is done. Write the date (YYYY-MM-DD) and who checked it. Use a role, such as "owner" or "counsel".
- "Claude Code" in the Owner column of a ticked row means an AI agent checked it read-only (production queries or the release records), not the owner. The owner may check it again and add their own date.
- If an item cannot be done yet, write "blocker" in Status and name an owner.
- The pilot starts when every item in section A is ticked. Teens join only when every item in section B is ticked too.
- Never write pilot users' names, emails or phone numbers here, or anywhere in the repo.

## B. Teen gate: before any teen is recruited

Until every item here is ticked, recruit adults only. The funnel shows adults only, and its under-18 column stays hidden. Feedback from minors stays off (WP 5.7 and 5.8) until counsel approves it separately.

The under-18 column is a server-side switch, `app_settings` key `funnel_minor_counts`, off by default. While it is off the funnel does not compute any under-18 or unknown-age number at all. Only a superadmin turns it on, from the Funnel card ("Turn on…", typing COUNSEL), with a reason that names counsel's sign-off and its date. The database refuses every other way to turn it on, and each change is an admin audit log entry (`feature_flag.update`, who, why). Tick B1 with the date of that entry.

The funnel's stored history (WP 5.3) is adults only and is never rewritten once a week is frozen. When an account that was counted as an adult is later found to be a minor (a corrected birthday or an admin age correction), a trigger deletes the stored weeks from the week that account was created. Those weeks are then counted live without it, and stored again the next night. So, with the switch off, no frozen week keeps a minor's activity in the adults' numbers. The cost is that those weeks lose the history's protection against deleted rows.
